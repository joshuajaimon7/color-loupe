# ColorLoupe Pro

> **Precision Pixel Eyedropper, 10-Step Tint/Shade Engine, WCAG 2.1 Auditor & 1-Click Tailwind Exporter**  
> Built by TinyStack Labs. 100% on-device, private, and zero tracking.

---

## Key Highlights

- **Pixel Eyedropper:** High-precision pixel color picker using native browser APIs across all web apps, images, videos, and canvases.
- **10-Step Shade System (50 to 950):** Automatically computes perceptual tint and shade design scales from any seed color.
- **1-Click Tailwind Exporter:** Generates ready-to-paste `tailwind.config.js` brand color blocks.
- **WCAG 2.1 Contrast Matrix:** Real-time luminance ratios on dark and light surfaces with AA/AAA pass/fail validation.
- **Color Blindness Simulation:** Linear RGB matrix models for Protanopia, Deuteranopia, Tritanopia, and Monochromacy.
- **Site-Wide Palette Extractor:** Discovers computed brand colors, text colors, and CSS gradients across any webpage.
- **Figma Design Tokens JSON:** Standardized JSON export for Figma Tokens Studio and Style Dictionary.

## Installation (Unpacked)

1. Clone or download this repository.
2. Open Google Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** in the upper right.
4. Click **Load unpacked** and select the `06-color-loupe` folder.
5. Open `demo-test.html` or any website and click **"Pick Pixel Color"**.
